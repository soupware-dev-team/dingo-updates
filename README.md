# Dingo for macOS updates

This public repository hosts signed, notarized Dingo for macOS downloads. Each release includes a `.dmg` and the corresponding Mac source archive under GPL-3.0-or-later. The development repository remains private.

Dingo checks the public GitHub release feed anonymously for updates. Release files contain application code and assets; they do not contain anyone's travel plans, gear, payments, or other personal app data. iPhone builds are distributed through TestFlight.

Download a release from the [Releases page](https://github.com/soupware-dev-team/dingo-updates/releases). Verify the macOS signature by opening the notarized disk image or with `spctl` and `codesign`.
